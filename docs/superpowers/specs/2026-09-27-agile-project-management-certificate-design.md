# Agile Project Management Certificate Design

## Goal

Add the completed Coursera course "Agile Project Management" to the portfolio's Courses & Training section.

## Design

- Add one certificate card as the first item in the existing Courses & Training grid.
- Reuse the current certificate card markup, styling, and `fade-up` animation.
- Display provider `Coursera` and title `Agile Project Management`.
- Use a project-management-related Font Awesome icon.
- Label the outbound action `Certificate` and link it to `https://coursera.org/share/ab1fc062c05497c67db27b851be16d17`.
- Open the certificate in a new tab with `rel="noopener"`, matching existing external links.

## Scope

Only `index.html` changes. No CSS, JavaScript, navigation, or unrelated content changes.

## Verification

- Confirm the card appears first under Courses & Training.
- Confirm markup matches surrounding cards and remains responsive through the existing grid styles.
- Confirm the certificate URL and external-link attributes are correct.
